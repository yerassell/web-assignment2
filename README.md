# web-assignment2

https://yerassell.github.io/web-assignment2/

This repository includes four tasks completed. Each html file has a navigation bar that links to each others.

## Brief description
- index.html contains Part 1 of the assignment. It contains Task 0 and Task 1. It consists a navigation bar and profile cards designed using Flexbox.
- task2.html is a webpage layout. It consists of navigation bar, header, sidebar, main content and footer, all styled using CSS Grid. The layout idea was taken from my first assignment's second task.
- task3.html is an Image Gallery that represents the arts of Claude Monet.
- task4.html is a Portfolio website that presents the websites created for assignments 1&2 so far.

## Instructions
To run the project:
1. Clone this repository to your local device (if Git is downloaded in your device)
   ```bash
   https://github.com/yerassell/web-assignment2.git
   ```
   If Git is not downloaded in your device, click the green button **Code** ath the right top of the repository, select **download ZIP**, unzip the downloaded file.
2. Open the project folder in your device
3. Open the html file inside any task folder. It will open and display the website on your default web browser. The navigation bar will guide you to other tasks.
